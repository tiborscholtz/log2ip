# Contributing to log2ip

Thank you for your interest in contributing to **log2ip**!  
Contributions of all kinds are - bug reports, feature requests, documentation improvements, and code contributions.

This document outlines the guidelines to help keep the project consistent, secure, and easy to maintain.

---

## Getting Started

1. **Fork** the repository
2. **Clone** your fork locally:
   ```bash
   git clone https://github.com/yourusername/log2ip.git
   cd log2ip
    ```
3. Create a new branch for your work:
  ```bash
  git checkout -b feature/your-feature-name
  ```
